# 全局世界书管理

SillyTavern 全局世界书管理扩展，当前版本 1.2.0。AI 辅助开发。

世界书太多、不好找、不想每次逐本开关时，可以用悬浮面板搜索、收藏、分类和切换组合。

## 安装

酒馆 → 扩展 → 安装扩展，粘贴仓库地址：

```text
https://github.com/x3117663836-lang/global-lore-manager
```

分支留空，点击“只给我安装”，安装后刷新页面。不依赖酒馆助手，不需要修改酒馆核心文件。酒馆服务器需要能够访问 GitHub。

已经手动安装同名文件夹的用户，请先备份账号设置和旧插件目录，再处理同名目录冲突；不要重复安装两个副本。

## 功能

- 名称搜索、中文拼音顺序排序、已启用/未启用筛选。不支持拼音首字母搜索。
- 星标收藏；收藏夹内也能开关、分类和打开原生世界书编辑器。
- 平级虚拟文件夹，一本书可属于多个文件夹。删除分类不删除世界书文件。
- 保存组合，支持替换全局列表、追加开启、关闭组合成员。
- 当前筛选结果批量开关，最近一次选择变更可撤销。
- 悬浮入口可拖动、调大小、隐藏；隐藏后可从扩展设置打开面板。

## 使用边界

只管理全局世界书启用列表，不修改条目正文、关键词、深度、注入顺序或角色/聊天绑定。通过其他入口绑定的世界书，不会因为全局关闭而一定停用。

收藏和分类不自动开启世界书。组合之间没有独立计数：关闭某组合成员，也会关闭其他组合共有的书。建议首次使用先保存“原配置”组合。

世界书改名或删除后，旧收藏/分类可能标记缺失，需要手动调整。撤销不是完整备份，刷新或外部更改会使其失效。停用扩展不自动还原启用列表。

## 数据与网络

完整可读运行源码随仓库公开，没有混淆。插件不调用模型、不注入提示词；开启更多世界书仍可能增加实际模型输入。

插件读取世界书名称及全局启用状态，将组合、收藏、分类和界面设置保存在当前账号的酒馆扩展设置中。没有统计上报、广告或遥测，不主动采集聊天正文、密码或 API 密钥。

插件运行新增的第三方请求域名：**无**。图标本地加载。目录读取、编辑器和设置保存仍通过酒馆原有机制访问自己的服务器。

通过 Git 安装/更新时，酒馆会访问 `github.com` 及 GitHub 下载基础设施；这与插件运行时联网不同。README 中的素材链接仅供手动查阅。
